# Skill catalog

Three organizations. They do not nest. Brand says whose film it is. Selection says what gets cut from the tape. Posting strategy says how signed videos later take a slot, and that organization is not in force yet.

Folders stay flat. This file is the map.

## 1. Brand

Whose queue the thought belongs to. Resolved from the video or folder name before any cut.

| | Where |
|--|--------|
| Skill | [`entity_brand`](entity_brand/SKILL.md) |
| Books | `brands/` — operator copies. Git ships `_template.md` only. |

| Entity | Book |
|--------|------|
| Tipper | `Tipper_Brand_Book.md` |
| THP | `the-hard-port-brief.md` |
| GAF | `GAF_Brand_Brief.md`, then `GAF_Brand_Book_Updated.md` |
| founder | Spoken style on every entity. Origin Story is not a Tipper, THP, or GAF launch. |

A finished thought that belongs to a sibling is leftover on this title. Vocabularies do not mix on one file. Founder spoken style stays on all three.

## 2. Selection

What gets cut. Take as many lands as the tape holds. A named list is not a cap.

| Step | Skill | Decides |
|------|-------|---------|
| Situation | [`situation_resolve`](situation_resolve/SKILL.md) | The thought finishes. Statement, pressure, land. |
| Vignette | [`story_snippet`](story_snippet/SKILL.md) | Story-shaped windows before the script. |
| Topics | [`detect_topics`](detect_topics/SKILL.md) | Candidate blocks. Not the cut. |
| Stage | [`flywheel_series`](flywheel_series/SKILL.md) | One stage on the cut: attract, engage, trust, service, referral, loop. The same stage repeats for every new land. A missing stage is skipped. |
| Short | [`extract_shorts`](extract_shorts/SKILL.md) | The script. 50–75s. One land per file. |
| Chunk | [`chunks`](chunks/SKILL.md) | 11–15 min. One job. On an episode, this is the service. |
| Script | the `.md` next to the deliverable | Signed before ffmpeg. |
